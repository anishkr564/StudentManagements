# Student-Management

A simple Python project to manage student records. This project is created to practice Git and GitHub operations such as commit, push, branching and merging.

## Features
- Add a new student (name and roll number)
- Display all students
- Search a student by roll number

## Technologies Used
- Python 3
- Git and GitHub

## Project Structure
```
Student-Management/
│── README.md
│── student.py
```

## How to Run
1. Clone the repository:
   ```
   git clone https://github.com/<your-username>/Student-Management.git
   ```
2. Go to the project folder:
   ```
   cd Student-Management
   ```
3. Run the program:
   ```
   python student.py
   ```

## Sample Output
```
1 - Amit
2 - Riya
```
